# Getting started

Questo file vive in una **sottocartella** (`guide/`), per verificare che l'albero nella sidebar gestisca correttamente più livelli.

## Passi

1. Apri una cartella dal pulsante in alto
2. Clicca un file nella sidebar per visualizzarlo
3. Usa `Ctrl+O` per aprire un file singolo, `Ctrl+Shift+O` per una cartella
