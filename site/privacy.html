# privacy

Privacy Policy

Last updated: August 27, 2026

MD Viewer is a local, offline-first desktop app: no account, no cloud, and — as far as the app and this website are concerned — nothing about you is collected, stored on a server, or sold. This page explains exactly what does and doesn't happen, in plain terms.

The desktop app

MD Viewer runs entirely on your own device. It opens the files and folders you point it at, and nothing else.

  • No accounts, no cloud sync. There's nothing to log into.
  • No telemetry, no analytics, no crash reporting. The app doesn't phone home — verified against its own source, not just claimed.
  • Settings stay on your device. Theme, language, and editor preferences are saved locally (in the app's own storage), never transmitted anywhere.
  • Remote content in your own files. If a Markdown file you open references a remote image or link, your device will request that content directly from wherever the file points — the same way a web browser would. That's a consequence of the file you opened, not something MD Viewer initiates on its own.

This website (mdviewer.mtsolutions.studio)

The site you're reading this on is a single static page with no forms, no accounts, and no analytics of any kind. Two things it does load from outside your browser, both standard and both worth naming honestly:

  • GitHub's public release API — to show the current version and the right download link for your platform, the page asks api.github.com for the latest release. That request goes from your browser directly to GitHub; this site never sees it.
  • Google Fonts — the page's typefaces (Manrope, Public Sans, JetBrains Mono) are loaded from Google's font servers, same as most websites that use Google Fonts. Your browser requests those font files directly from Google.

Neither of those is something this site collects or has access to — they're requests your own browser makes to a third party, standard for a page that shows live release info and uses web fonts.

Cookies

Neither the app nor this website use cookies. See the Cookie Policy for the full, short answer.

Changes to this page

If MD Viewer ever starts doing something that isn't described here — an optional update checker, for instance — this page will be updated first, and the change will be described honestly, not buried.
